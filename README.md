# JVK Portfolio

Portfolio estático para GitHub Pages, sem etapa de build.

## Estrutura

- `index.html` — entrada do portfólio
- `assets/` — imagens e fontes locais
- `css/` e `js/` — estilos, navegação e conteúdo
- `projects/` — demonstrações independentes
- `CNAME` e `.nojekyll` — configuração do GitHub Pages

## Publicação

No GitHub, configure o Pages para publicar a partir da branch principal e da raiz (`/`). O domínio personalizado é definido pelo arquivo `CNAME`.

As pastas em `_archive/` são cópias antigas mantidas apenas como backup local e ficam fora do commit pelo `.gitignore`.
